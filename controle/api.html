API

Esta seção apresenta uma visão geral dos recursos disponibilizados pelo SME-Identidade-Admin-Microsserviço.

Autenticação

Todos os endpoints administrativos utilizam autenticação por API Key.

A chave deve ser enviada no cabeçalho HTTP configurado pela variável de ambiente API_KEY_HEADER.

Exemplo:

X-API-Key: <API_KEY>

Caso a chave seja inválida ou esteja ausente, a requisição será rejeitada com HTTP 401 (Unauthorized).
